* 类似: construction

## architecture

* 类似: architecture

* what you worry about: domains
* indicative books: 📙 Martin clean architecture

## system

* 类似: urban planning
* what you do: diagrams / conf
* what you worry about: consensus, perf
* indicative books: 📙 Ejsmont web scalability, Kleppmann data-intensive applications
